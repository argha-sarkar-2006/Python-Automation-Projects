# 📧 Gmail Automation Project

This Python project allows you to **send personalized automated emails** using Gmail, with support for HTML templates and environment-based credentials. Perfect for bulk emailing or automating regular tasks like notifications or newsletters.

---

## 🚀 Features

- Send automated HTML emails using Gmail
- Uses environment variables for secure credentials
- Simple console-based UI
- Supports email templating with placeholders (e.g., name)
- Lightweight and beginner-friendly
- Use Your Own google app password 
- Use this Link to generate one _https://myaccount.google.com/apppasswords
